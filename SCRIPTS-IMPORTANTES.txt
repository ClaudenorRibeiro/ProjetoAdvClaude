SCRIPTS DO PROJETO — O QUE CADA UM FAZ E SE PODE APAGAR
=======================================================
Regra: todo script do projeto traz, nas primeiras linhas, o aviso
"IMPORTANTE — NÃO APAGAR" (ou "TEMPORÁRIO — pode apagar depois de ...").
Este arquivo é o índice. Se um script não estiver aqui, pergunte antes de apagar.

PARA RODAR NO PC (duplo clique)
  iniciar_pc_casa.bat / iniciar_pc_escrit.bat   IMPORTANTE  Liga o sistema neste PC.
  parar_pc_casa.bat / parar_pc_escrit.bat       IMPORTANTE  Desliga o sistema (fecha TODAS as janelas do Prompt de Comando).
  salvar_RASCUNHO_do_GIT_no_pc.bat              IMPORTANTE  Baixa o rascunho do GitHub para testar.
  salvar_pc_casa_no_Git.bat / ..._escrit_...    IMPORTANTE  ENVIA para o main (produção). Uso exclusivo do usuário.
  TESTAR-SISTEMA.bat                            IMPORTANTE  Bateria de testes (rápida; "completo" ou "profundo" como argumento). Ao terminar a janela só fecha no X.
  TESTAR-COMPLETO.bat                           IMPORTANTE  Bateria COMPLETA (de 10 a 60 min, conforme o PC). Instala sozinha o que faltar. Ao terminar a janela só fecha no X (nenhuma
                                                            tecla fecha) e o resultado todo fica salvo em quality\test-results\ultima-bateria.txt (fora do Git).
