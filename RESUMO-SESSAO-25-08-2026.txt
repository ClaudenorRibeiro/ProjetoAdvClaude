3. FEATURE NOVA — ASSUNTOS DOS PROCESSOS

Pedido:

- Criar campo “Assuntos” no cadastro/edição de processo.
- O processo pode ter vários assuntos.
- O usuário pode escolher vários assuntos por checkbox.
- O botão “...” cadastra novos assuntos.
- Não pode haver duplicidade.
- Depois o usuário acrescentou que “Assuntos” deve entrar na lista de permissões.
- Somente quem tiver permissão pode cadastrar, editar ou excluir assuntos.

Decisão técnica:

- Como um processo pode ter vários assuntos, não foi usada uma coluna simples em tblproc.
- Foi criada estrutura normalizada:
  - cadastro de assuntos;
  - vínculo entre processo e assunto.
- Isso evita redundância e mantém a busca/filtro eficiente e escalável.

SQL criado:

- sql_assuntos_processos_para_heidi.sql

Tabelas criadas pelo SQL:

- tblassuntoproc
- processo_assunto

Observações importantes:

- O Codex não executou esse SQL no banco.
- O usuário roda no HeidiSQL.
- O SQL foi pensado para local primeiro, depois AWS.
- As tabelas estão em letras minúsculas.
- Há trava para não repetir o nome do assunto.
- Há trava para não repetir o mesmo assunto no mesmo processo.
- O vínculo com processo evita órfãos.

Erro ocorrido no HeidiSQL:

- O usuário rodou o SQL inicialmente no banco errado, ac_portaria.
- O erro apareceu porque esse banco não tinha a tabela tblproc.
- Foi orientado desfazer no banco errado removendo as tabelas novas se tivessem sido criadas ali.
- Depois, o SQL deveria ser rodado no banco correto do sistema de advocacia.

Backend alterado:

- backend/src/controllers/processosController.js
- backend/src/routes/index.js

O que entrou no backend:

- Criar processo grava os assuntos selecionados dentro da transação.
- Editar processo substitui os assuntos dentro da transação.
- Buscar pasta retorna os assuntos de cada processo.
- Auxiliares de processo retornam assuntos ativos.
- Criado CRUD de assuntos.
- Criar, editar e excluir assuntos exigem permissão processos.assuntos.
- Excluir assunto bloqueia se já estiver vinculado a processo.
- Excluir assunto usa transação.
- Exclusão definitiva de processo limpa também os vínculos em processo_assunto.

Regra do filtro:
