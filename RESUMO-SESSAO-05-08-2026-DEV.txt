1) NOTIFICAÇÃO DE CONCLUSÃO DE TAREFA E PRAZO (feature principal)
   O QUE É: ao CRIAR (e depois também ao EDITAR) uma Tarefa ou um Prazo, existe
   uma opção "🔔 Avisar-me quando for concluída/concluído". Se ligada, quando a
   PESSOA ATRIBUÍDA marcar como concluída, o CRIADOR recebe um aviso no sino:
     - Tarefa: "A tarefa 'XXXX' foi concluída por Fulano"
     - Prazo:  "O prazo 'XXXX' foi concluído por Fulano"

   REGRAS (decididas por você via perguntas):
   - Canal: SOMENTE o sininho (sem e-mail).
   - Vale para Tarefa E Prazo.
   - A opção só fica DISPONÍVEL quando há um usuário responsável (Atribuir/Delegar
     diferente de "Escritório"). Se você trocar para "Escritório", a caixinha
     desabilita e se desmarca sozinha.
   - NÃO avisa se foi o próprio criador que concluiu (evita aviso à toa).
   - O aviso é gravado DENTRO da mesma transação da conclusão (tudo ou nada).
   - Sem órfãos: se a Tarefa for excluída, a notificação some junto (FK CASCADE).

   ONDE MEXEU:
   - Banco (SQL rodado): coluna "notificar_conclusao" em 'tarefas' e em
     'prazos_processo'; a tabela 'notificacoes' passou a servir também tarefas
     (o campo do prazo virou opcional e entrou um campo para a tarefa, com
     amarração que apaga a notificação junto se a tarefa for excluída).
   - Backend: serviço de notificação ganhou a função de aviso de conclusão
     (transacional); controllers de tarefas e prazos gravam a opção no criar/
     editar e disparam o aviso na conclusão; as listagens passaram a devolver a
     opção para a tela pré-marcar a caixinha.
   - Frontend: as janelas de Nova Tarefa, Novo Prazo e Editar Prazo ganharam a
     caixinha; o sino (topo da tela) exibe o aviso.

   >>> BUG PRÉ-EXISTENTE CORRIGIDO DE BRINDE (você aprovou — "opção A"):
   A listagem de tarefas NÃO devolvia o "responsável" (só o nome dele). Efeito:
   ao EDITAR uma tarefa que era de um usuário, o campo "Atribuir para" abria como
   "Escritório" e, se salvasse, a tarefa PERDIA o responsável. Corrigido: a
   listagem passou a devolver o responsável, então o editar agora pré-seleciona
   certo (e o guard da caixinha 🔔 funciona no editar). O Prazo NÃO tinha esse bug.

ALTER TABLE `tarefas`
  ADD COLUMN `notificar_conclusao` tinyint(1) NOT NULL DEFAULT 0 AFTER `criado_por`;

ALTER TABLE `prazos_processo`
  ADD COLUMN `notificar_conclusao` tinyint(1) NOT NULL DEFAULT 0 AFTER `criado_por`;

ALTER TABLE `notificacoes`
  MODIFY COLUMN `prazo_id` int DEFAULT NULL,
  ADD COLUMN `tarefa_id` int DEFAULT NULL AFTER `prazo_id`,
  ADD KEY `idx_notif_tarefa` (`tarefa_id`),
  ADD CONSTRAINT `fk_notif_tarefa` FOREIGN KEY (`tarefa_id`) REFERENCES `tarefas` (`id`) ON DELETE CASCADE;
